# 08. Различия харнессов

Код хуков один. Различия — в том, как харнесс их регистрирует, что присылает и что
делает с ответом. Флаг `--harness` говорит коду, где учесть эти различия.

| | Claude Code | GigaCode | Codex |
|---|---|---|---|
| Упаковка | плагин (`.claude-plugin/`) | расширение (`gigacode-extension.json`) | плагин (`.codex-plugin/`) |
| Регистрация хуков | `hooks/hooks.json` | ключ `hooks` в манифесте расширения | `hooks/hooks-codex.json` |
| Путь к хуку в команде | `${CLAUDE_PLUGIN_ROOT}` | `${extensionPath}${/}` | `${PLUGIN_ROOT}` |
| Единица таймаута | секунды | миллисекунды | секунды |
| Как роутер попадает в контекст | вывод `SessionStart` | `contextFileName` / `GIGACODE.md` | вывод `SessionStart` |
| Инструменты записи | `Write`, `Edit`, `MultiEdit` | `write_file`, `edit`, `replace` | `apply_patch` (+ `Edit`, `Write`) |
| Shell | `Bash` | `run_shell_command` | `Bash`, `exec_command` (команда массивом) |
| Блок до записи Java-правилами | да | да | нет: из патча не виден итоговый текст, нарушения приходят после |
| Событие сжатия | `SessionStart` с `source: compact` | `PostCompact` | `SessionStart` с `source: compact` |
| `context_usage` в `Stop` | нет | да | нет |
| Якорь по умолчанию | выключен | включён | выключен |
| Одобрение хуков | плагин — при установке; проект — доверенная папка | включены по умолчанию, `disableAllHooks` выключает | доверие в `/hooks` |
| Проверено вживую | да (CLI 2.1.287) | да (26.11.141) | нет |

## Якорь по умолчанию только в GigaCode

Так задано в спецификации v0.1 (R-ANCHOR-3): GigaCode — основная рабочая среда, где
якорь нужен; в Claude Code и Codex он по умолчанию выключен, а блок восстановления после
сжатия работает везде. Это только значение по умолчанию: ключ `anchor` в
`forbxpg-java.json` включает или выключает якорь в любом харнессе. Адаптивный якорь
(правила из нарушений и ролей файлов этой сессии) запланирован на v0.3.

## Почему GigaCode получает роутер не через хук

Через `contextFileName` GigaCode кладёт файл в контекст сам и управляет им при сжатии.
Печать того же текста хуком `SessionStart` дала бы два экземпляра роутера.

## Переменные окружения папки проекта

Хук берёт папку сессии из первой непустой: `CLAUDE_PROJECT_DIR`, `GIGACODE_PROJECT_DIR`,
`QWEN_PROJECT_DIR`, затем `cwd` из входа хука, затем текущую папку процесса. Дальше от
неё ищется корень Maven-проекта ([02](02-hooks-explained.md#как-хук-находит-проект)).

## Windows

- Хуки запускаются как `node ...` из `cmd`: ни bash, ни PowerShell не нужны.
- Пути с `\` нормализуются; сравнение путей файлов с ошибками компилятора — без учёта
  регистра и через реальный путь.
- Компиляция: `mvnw.cmd` через shell, по таймауту `taskkill /T /F` убивает всё дерево
  `cmd → mvn → java`.
- CI гоняет все тесты на Windows, Linux и macOS с Node 20 и 22.
