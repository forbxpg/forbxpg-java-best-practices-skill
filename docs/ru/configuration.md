# Настройка

Необязательный JSON: `forbxpg-java.json` в корне проекта или `~/.forbxpg-java.json` для всех
проектов. Файл проекта побеждает по каждому ключу. Без файла — значения по умолчанию.

```json
{
  "anchor": null,
  "stopCompile": true,
  "contextWarnAt": 0.7,
  "disable": [],
  "updateCheck": true
}
```

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `anchor` | `null` → включён в GigaCode, выключен в Claude Code и Codex | якорь на каждое сообщение: паспорт и три правила, сначала нарушенные в этой сессии |
| `stopCompile` | `true` | компилировать изменённые модули в конце хода |
| `contextWarnAt` | `0.7` | доля заполнения контекста, при которой модель один раз просят записать handoff (заполнение сообщает GigaCode) |
| `disable` | `[]` | id правил, выключенных для проекта, например `["J3"]` для CLI, который пишет в `System.out` |
| `updateCheck` | `true` | раз в сутки искать тег новой версии и сообщать о ней при старте сессии; `false` выключает (переменная окружения `FORBXPG_JAVA_UPDATE_CHECK=0` выключает для всей машины или CI) |

Выключение — решение пользователя: заблокированной модели велено остановиться и спросить, а не
править этот файл самой. Смысл правила меняется в скилле и хуках вместе с тестами.
